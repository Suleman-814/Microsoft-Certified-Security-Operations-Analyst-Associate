Mitigate Threats Using Microsoft Security Copilot


Overview
This learning path focuses on understanding and using Microsoft Security Copilot to investigate, analyze, and mitigate security threats with the help of generative AI. It covers generative AI fundamentals, large language models (LLMs), prompts, AI agents, Microsoft Security Copilot features, plugins, promptbooks, and embedded experiences across Microsoft security solutions.

Modules Covered
1. Introduction to Generative AI and Agents
Understand the fundamentals of generative AI and how it powers modern applications. Explore large language models (LLMs), prompts, and AI agents. Learn how generative AI can assist with security operations and threat investigation.

2. Describe Microsoft Security Copilot
Get introduced to Microsoft Security Copilot and its capabilities. Understand basic terminology, how Security Copilot processes prompts, and the key elements of an effective prompt. Learn how to enable and get started with Microsoft Security Copilot.

3. Describe the Core Features of Microsoft Security Copilot
Explore the core capabilities of Microsoft Security Copilot. Learn about available plugins, promptbooks, exporting and sharing information, and other features that help security professionals improve investigation and response workflows.

4. Describe the Embedded Experiences of Microsoft Security Copilot
Understand how Microsoft Security Copilot integrates directly into Microsoft security products. Explore embedded Copilot experiences across Microsoft's security solutions and learn how AI-assisted capabilities support security investigations and operations.

5. Experience Security Copilot Through Guided Simulations
Gain practical experience with Microsoft Security Copilot through interactive guided simulations. Explore standalone and embedded experiences, work with prompts and promptbooks, and investigate scenarios involving Microsoft Purview and Microsoft Defender XDR.
