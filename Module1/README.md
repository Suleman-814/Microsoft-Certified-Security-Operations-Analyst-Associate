**Mitigate Threats Using Microsoft Defender XDR**


**Overview**

This learning path focuses on investigating, responding to, and mitigating security threats using Microsoft Defender XDR and its integrated security solutions.
It covers incident management, threat remediation, identity protection, identity threat detection, and cloud application security.

**Modules Covered**

1. Introduction to Microsoft Defender XDR Threat Protection
Understand Microsoft Defender XDR and its integrated threat protection capabilities.
Explore how Microsoft security products work together to detect and respond to threats.

2. Mitigate Incidents Using Microsoft Defender
Investigate and manage security incidents in the Microsoft Defender portal.
Analyze alerts and correlate security events.
Understand incident response and threat mitigation workflows.

3. Remediate Threats Using Microsoft Defender
Investigate and remediate email-based threats using Microsoft Defender for Office 365.
Perform phishing triage and use automated investigation tools.
Understand attack simulation and threat remediation.

4. Manage Microsoft Entra Identity Protection
Monitor user sign-ins and identity risk.
Investigate risky users and sign-ins.
Explore Microsoft Entra ID Protection capabilities and policies.

5. Safeguard Your Environment with Microsoft Defender for Identity
Understand Microsoft Defender for Identity.
Detect and investigate identity-based threats.
Learn how to protect identities and identify suspicious activities.

6. Secure Your Cloud Apps and Services with Microsoft Defender for Cloud Apps
Understand Cloud Access Security Broker (CASB) capabilities.
Monitor cloud applications and control data movement.
Detect suspicious activities and investigate cloud-related threats.
